## GaiaColibri — Site Institucional

Site institucional da Gaia Colibri Treinamentos, consultoria especializada em Desenvolvimento Humano & Liderança. Desenvolvido do zero com HTML, CSS e JavaScript puro, sem frameworks.

## 📋 Visão Geral

O site apresenta os serviços, metodologias e diferenciais da consultoria, com foco em conversão de leads através de um formulário de contato completo integrado a um backend PHP + MySQL.

## 🛠️ Tecnologias

HTML5 

CSS3 

JavaScript (ES6+)

PHP 8+

MySQL

Bootstrap Icons
